# Proyecto_Sicet
# Proyecto de html5, css3, bootstrap5, python
SICET es un sistema web desarrollado como proyecto de formacion del programa Tecnologo en Analisis y Desarrollo de Software (ADSO) del Sena

- contiene:
- Registro de usuarios
- Registro de dispositivos electronicos
- Asociacion de dispositivos con sus respectivos propietarios
- Generacion y visualizacion de codigos QR
- Control de ingreso y salida de dispositivos
- Consulta del historial de movimientos
- Generacion de reportes por fechas, usuarios y dispositivos
- Inicio de sesion y gestion de acceso administrativo
